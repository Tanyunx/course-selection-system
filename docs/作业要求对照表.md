## 三个硬缺口

### 缺口 A：域名

申请免费域名有两条路，**但这里有个必须先说清的坑**：

> **中国大陆地域的云服务器，用域名对外提供 Web 服务需要 ICP 备案。**
> 未备案的域名解析到 `124.223.224.187`（上海），80/443 端口会被拦截，浏览器打不开。
> 备案周期通常 1～3 周，赶不上「下次课」是常态。

三条可选路线：

| 方案 | 能否立即用域名 | 成本 | 说明 |
|:--|:--:|:--|:--|
| **只用 IP 访问** | 不需要域名 | 0 | 课堂演示完全够用，`http://124.223.224.187` 直接访问 |
| **换境外地域实例** | ✅ 免备案 | 需重购实例 | 把实例换成**中国香港**等地域，域名可立即解析并签发 HTTPS |
| **走备案** | ✅ 备案后 | 0 元但耗时 | 腾讯云提供免费备案服务，周期 1～3 周 |

域名本身可以免费拿：腾讯云 / 阿里云不定期有 `.top` / `.xyz` / `.cn` 首年免费活动（需实名认证）。Freenom 那类免费顶级域已基本停止对外服务，不建议再考虑。

**我的建议**：先用 IP 完成部署与验收（满足「部署云服务器」这条），域名与 HTTPS 作为加分项后补。这样不阻塞主线。

### 缺口 B：HTTPS 证书

`deploy.sh` 里已经写好这段：拿到域名后加 `--domain` 与 `--email`，脚本会自动用 certbot 向 Let's Encrypt 申请证书、配置 80→443 跳转、并开启自动续期。

前置条件只有两个：① 域名已解析到服务器 IP；② 80 端口可从公网访问（用于完成 ACME 校验）。

> 关于「跨域」：作业里这个括号指的是**跨域访问控制**，这一项**已经做了**——`WebConfig` 里按白名单放行来源，`allowCredentials(false)`，预检请求正确响应。HTTPS 是独立的一件事，两者不要混。等域名定下来，建议把 `CORS_ORIGINS` 从 `*` 收敛成实际域名，这在作业答辩里是个能讲的点。

### 缺口 C：云服务器部署

`deploy.sh` 已覆盖完整链路：装 JDK 21 → 装 Maven → 装并初始化 PostgreSQL → 幂等建库建角色 → 生成 `.env`（权限 600、口令随机）→ 构建 jar → 一次性导入演示数据 → 注册 systemd 服务（开机自启、崩溃重启）→ 配置 Nginx 托管前端 + `/api` 反向代理 → 可选 HTTPS。

1. 服务器的 SSH 登录方式（密码或密钥），我在你的授权下执行部署；**或**
2. 你自己在腾讯云网页终端里执行，我在旁边盯日志、随时排查；**或**
3. 我先把部署步骤整理成一份「逐条复制即用」的命令清单，你完全自主执行。

## 关于你本机装的 PostgreSQL

我实测了一下：

```
C:\Program Files\PostgreSQL\18\    ← 程序目录存在（bin / pgAdmin 4 / share 都有）
C:\Program Files\PostgreSQL\18\data ← 不存在
Windows 服务列表                     ← 没有 postgres 服务
```

## 口径上容易踩的两个点

**① 「mock 数据」和「模拟数据」不是一回事。**
作业说「开始时数据可以先用 mock，保存在本地的 json 数据」——这在阶段一做了，`frontend/mock/` 六个文件（40 KB）就是，可以脱离后端跑通全流程。但**现在运行的系统不是 mock**：数据落在 PostgreSQL 的 18 张物理表里，请求走 `HTTP → Spring Boot → JDBC → 数据库`，唯一约束、外键、触发器、行级锁全部生效。证据是 `t_audit_log` 里留着每次登录的记录——mock 的话数据库根本不会留下痕迹。

**② 「数据冲突要在数据库控制」不是「在代码里 if 一下」。**
这是本次设计的重点。占座用的是条件更新：

```sql
UPDATE t_course_offering
   SET enrolled = enrolled + 1
 WHERE id = ? AND enrolled < capacity AND status <> 0
```

「判断余量」与「自增」由 PostgreSQL 的行锁保证原子完成，**受影响行数为 0 就说明没抢到**，不存在「先查后改」之间的时间窗。换课是单事务「先占后放」，候补取号用 `FOR UPDATE` 串行化。并发实测的直接输出：容量 3 的课，8 人同时选 → 结果码 `0,2001,2001,2001,2001,2001,0,0`（恰好 3 成功），库里 `enrolled=3`。
